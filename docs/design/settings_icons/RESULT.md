# 설정 화면 상위 탭 아이콘 선정

`app/web/index.html`의 설정 탭 7개와 각 탭 내용을 읽고 선정했습니다. 기존 컬러 이모지 방식에 맞추며, 왼쪽 메뉴 아이콘과는 겹치지 않습니다. 요청서 목록 외에 실제 왼쪽 메뉴에 있는 📝(항목별 기록)도 피했습니다.

| 탭 이름 | 이모지 | 고른 까닭 한 줄 |
| --- | --- | --- |
| 연결·모델 | 🔌 | OpenRouter·OCR의 API 연결과 모델 사용 준비를 플러그로 나타냅니다. |
| 역할·학년도 | 🏫 | 담임·비담임 역할과 학년도 설정을 함께 아우르는 학교 상징입니다. |
| 분량·일정 | 📅 | 생기부 마감과 D-day를 바로 떠올리게 하며, 분량 설정은 탭 글자로 함께 안내합니다. |
| 행특 사전 | 🧩 | 이미 본문의 ‘행특 설계 사전’과 ‘행특 설계’ 카드에서 쓰는 상징을 이어 연결감을 줍니다. |
| 백업·자료 | 💾 | 자료 저장·백업·복원을 직관적으로 나타내고, 왼쪽 메뉴의 가져오기·내보내기와 구별됩니다. |
| 앱 정보 | ℹ️ | 앱 이름·버전·제작자와 업데이트 확인이 있는 정보 화면임을 나타냅니다. |
| 제안하기 | 📮 | 의견을 보내는 우체통이라는 뜻이 명확하고 본문·버튼과도 일치하므로 기존 아이콘을 유지합니다. |

## 그대로 복사할 버튼 글자

```text
🔌 연결·모델
🏫 역할·학년도
📅 분량·일정
🧩 행특 사전
💾 백업·자료
ℹ️ 앱 정보
📮 제안하기
```

## 함께 검토한 후보

- 연결·모델 — 🔑: API 키 입력에는 맞지만 모델 선택·OCR 연결까지 나타내기에는 🔌가 더 포괄적입니다.
- 역할·학년도 — 🎓: 학년도를 연상시키지만 졸업·학생의 의미가 강해 교사의 역할 설정까지 담는 🏫를 골랐습니다.
- 분량·일정 — 📏: 목표 바이트 분량을 강조하려면 이 후보도 적합합니다. 추천안은 마감 일정을 빠르게 알아보는 📅입니다.
- 행특 사전 — 📒: 사전·설명 모음이라는 뜻은 있으나, 앱 안에서 이미 쓰는 🧩와의 일관성을 우선했습니다.

## 문자·표시 확인

| 이모지 | 실제 코드 포인트 | 변형 선택자 |
| --- | --- | --- |
| 🔌 | U+1F50C | 불필요 |
| 🏫 | U+1F3EB | 불필요 |
| 📅 | U+1F4C5 | 불필요 |
| 🧩 | U+1F9E9 | 불필요 |
| 💾 | U+1F4BE | 불필요 |
| ℹ️ | U+2139 U+FE0F | **U+FE0F 포함 필수** |
| 📮 | U+1F4EE | 불필요 |

위 표와 복사용 글자의 `ℹ️`에는 이모지 표시를 요청하는 U+FE0F를 실제로 붙였습니다. 나머지 6개는 기본 이모지 표시 문자입니다. 문자 조합은 [Unicode Emoji Test Data 16.0](https://unicode.org/Public/emoji/16.0/emoji-test.txt)를 기준으로 확인했습니다.

Windows의 Segoe UI Emoji와 Mac의 Apple Color Emoji에서 컬러로 제공되는 이모지를 골랐습니다. 이 중 가장 늦게 추가된 🧩도 [Windows 10 October 2018 Update](https://emojipedia.org/microsoft/windows-10-october-2018-update/puzzle-piece)와 [Apple iOS 12.1의 컬러 이모지 세트](https://emojipedia.org/apple/ios-12.1/puzzle-piece)에 수록되어 있습니다. 아주 오래된 운영체제는 해당 글꼴 지원이 필요하며, 운영체제별 색·모양은 다를 수 있습니다. 이번 작업에서 Windows WebView2·Mac 앱 실화면을 실행해 확인하지는 않았습니다.

## 작업 범위

이 결과 문서만 작성했습니다. 앱 파일은 수정하지 않았고, Chrome 실행이나 텔레그램 등 외부 전송도 하지 않았습니다.
