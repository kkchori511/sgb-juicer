# 설정 화면 상위 탭 버튼 아이콘 요청

## 할 일
설정 화면 맨 위 탭 버튼 7개에 아이콘을 하나씩 붙일 아이콘을 골라 주세요.

- 버튼 위치: `app/web/index.html` 231~237줄(`data-stab` 버튼)
- 지금 버튼 글자: 연결·모델 / 역할·학년도 / 분량·일정 / 행특 사전 / 백업·자료 / 앱 정보 / 📮 제안하기
- '제안하기'에는 이미 📮가 붙어 있습니다. 나머지 6개와 어울리는지 보고, 바꾸는 게 낫다면 바꿔도 됩니다.

## 맞출 것
- 앱의 다른 아이콘은 모두 **컬러 이모지**입니다(왼쪽 메뉴: 📊 현황판, 📥 자료 Inbox, 🔖 태그별 기록, 📤 검토 / 내보내기, 👥 명렬 / 담당 관리, 🏷️ 태그 관리, 💬 프롬프트, 📚 성취기준 / 활동 개요, ⚙️ 설정, 📖 사용 안내, ⚠️ 유의 사항). 같은 방식으로 이모지를 골라 주세요.
- 왼쪽 메뉴 아이콘과 겹치지 않게 해 주세요(같은 이모지를 쓰면 다른 화면으로 오해함).
- Windows(WebView2, Segoe UI Emoji)와 Mac(Apple Color Emoji)에서 모두 컬러로 나오는 이모지만 써 주세요. 변형 선택자(U+FE0F)가 필요한 이모지는 붙여서 적어 주세요.
- 탭 내용 참고: 각 탭 내용은 `index.html`의 `data-stab-content="…"` 영역(240줄부터)에 있습니다.
