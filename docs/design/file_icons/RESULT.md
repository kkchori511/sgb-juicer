# 파일 형식 아이콘 결과

같은 문서 틀에 파일 형식 글자를 얹은 SVG 3개를 만들었습니다.

| 파일 | 색 | 표시 |
| --- | --- | --- |
| [xlsx.svg](xlsx.svg) | 테두리 `#217346` / 글자 `#17603a` | 굵은 X |
| [pdf.svg](pdf.svg) | 테두리 `#d93025` / 글자 `#b3261e` | PDF 글자 띠 |
| [hwpx.svg](hwpx.svg) | 테두리 `#1f6fd1` / 글자 `#1557a8` | 직접 구성한 ‘한’ |

## 모양

- 세 아이콘 모두 `viewBox="0 0 24 24"`이며, 오른쪽 위가 접힌 흰 문서와 같은 위치·크기의 연한 색 글자 띠를 씁니다.
- 문서·접힘·띠의 테두리는 모두 1.5 단위입니다. 바깥 여백은 가로 약 0.75, 세로 약 0.75 단위로 최소화했습니다.
- 작은 크기에서도 식별할 수 있도록 본문 줄·격자·장식은 생략했습니다. 흰 바탕과 연한 색 버튼 모두에서 테두리와 진한 글자가 드러납니다.
- X·PDF·한은 모두 직접 만든 `path`입니다. SVG 안에 `text`, 외부 파일, 폰트 참조, 스크립트를 넣지 않았습니다. 문서 바깥은 투명합니다.

## 회사 로고와 다르게 한 점

회사 로고를 가져오거나 따라 그리지 않고, 세 파일에 공통인 접힌 문서와 가로 띠를 직접 구성했습니다. Excel의 겹친 타일·표 무늬, Acrobat의 곡선 심벌, 한컴의 고유 심벌 대신 일반적인 파일 형식 글자만 사용했습니다.

## 미리보기·확인

[preview.png](preview.png)는 세 아이콘을 나란히 16·24·48px로 보여 줍니다. 각 크기에서 흰 버튼과 해당 형식의 연한 색 버튼을 함께 배치했습니다. 파랑 배경은 `#eaf2fe`입니다.

SVG 구조와 글자가 실제 패스인지 확인하고, Mac AppKit으로 SVG를 직접 렌더링한 미리보기를 확인했습니다. Windows WebView2에서는 실행하지 않았습니다.

## 작업 범위

이 폴더의 SVG 3개, 미리보기 PNG, 결과 문서만 만들었습니다. 앱 파일은 수정하지 않았으며 Chrome 실행이나 텔레그램 등 외부 전송도 하지 않았습니다.
