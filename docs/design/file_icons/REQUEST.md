# 파일 형식 아이콘 3개 요청 (엑셀 / PDF / 한글)

## 할 일
버튼 글자 앞에 붙일 파일 형식 아이콘 SVG 3개를 그려 주세요.

- `xlsx.svg` — 엑셀: 초록, 문서 위에 'X' 느낌
- `pdf.svg` — PDF: 빨강, 문서 위에 'PDF' 글자 띠
- `hwpx.svg` — 한글: 파랑, 문서 위에 '한' 글자

## 지킬 것
- **회사 로고를 베끼지 마세요.** Microsoft Excel, Adobe Acrobat, 한컴 한글의 실제 아이콘·로고 모양을 따라 그리면 상표 문제가 됩니다. 색과 파일 형식만 알아볼 수 있는 **우리 고유 디자인**으로 그려 주세요.
- 세 개가 **같은 틀**이어야 합니다: 같은 문서 모양(오른쪽 위 모서리 접힘 등), 같은 크기·여백·선 굵기, 같은 글자 띠 위치. 색과 안의 글자만 다르게.
- 색은 버튼 색과 맞춰 주세요.
  - 엑셀 초록: 테두리 `#217346`, 진한 글자 `#17603a`
  - PDF 빨강: 테두리 `#d93025`, 진한 글자 `#b3261e`
  - 한글 파랑: `#1f6fd1` 근처, 진한 글자 `#1557a8` 근처
- 작은 크기(버튼 글자 옆 16~18px)에서 알아볼 수 있게 단순하게. 가는 선·작은 글자 여러 개는 피해 주세요.
- 글자는 SVG 안에서 `<text>`가 아니라 **패스(path)** 로 만들어 주세요(PC마다 글꼴이 달라 모양이 바뀌지 않게).
- `viewBox="0 0 24 24"`, 가로·세로 같은 비율, 바깥 여백 거의 없이. 외부 파일·폰트 참조 없이 SVG 하나로 완결.
- 흰 바탕 버튼과 연한 색 바탕 버튼(연한 초록 `#e9f5ee` / 연한 분홍 `#fdecea` / 연한 파랑) 위에서 모두 또렷해야 합니다.
