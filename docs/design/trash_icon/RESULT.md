# 휴지통 픽토그램 제작 결과

## 만든 파일

- [`app/web/icons/trash.svg`](../../../app/web/icons/trash.svg): 332바이트. `viewBox="0 0 24 24"`, 기본 크기 24×24, 투명 배경, 단색 `#ba1734`. 손잡이가 있는 뚜껑, 아래로 조금 좁아지는 몸통, 몸통 안 세로줄 2개로 구성했다. 선 굵기는 모두 2이며 끝과 꺾임은 둥글다. 글자·그라데이션·외부 참조가 없는 SVG 경로 3개다.
- [`preview.png`](preview.png): 600×180px. 흰 바탕에서 실제 SVG를 각각 16px·32px·64px로 렌더링한 미리보기다.

## 확인 방법

1. 로컬 Swift/AppKit의 SVG 렌더러로 원본 SVG를 읽어 미리보기 PNG를 만들었다. 브라우저는 사용하지 않았다.
2. 완성된 미리보기를 직접 열어 각 크기에서 손잡이·뚜껑·몸통·세로줄이 보이고, 선이 잘리거나 겹쳐 뭉개지지 않는지 확인했다. 작은 크기의 식별을 위해 내부 선은 2개로 단순화했다.
3. XML 파싱으로 SVG 구문, viewBox, 단일 색, 투명 채움, 2px 선 굵기와 둥근 끝 속성을 확인했다.

앱 연결은 하지 않았다. `app.js`, `style.css`, `index.html`은 수정하지 않았으며, Chrome 실행·외부 전송 없이 로컬에서만 제작·확인했다.
