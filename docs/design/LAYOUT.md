# 생기부 착즙기 화면 구성 (확정안, 2026-11-08)

요구사항·규칙: `docs/REQUIREMENTS.md`(특히 J절). 과정 기록: `LAYOUT_DRAFT.md`(1차안), `codex_ux_review.md`(Codex 검토).
디자인 바탕: 악필교정기(블루그레이 배경, 흰 입력칸, 파란 기본 버튼, 지침|예시 좌우, 진행 창).

```

│ ───────────     │                                                                     │
│ 명렬·담당 관리   │                                                                     │

```
- [≡]로 메뉴 접기/펼치기(접으면 아이콘 줄, 본문 확장, 상태 기억).
- 버전 버튼 → "선생님의 자료 한 방울까지 생기부에 넣겠습니다." / "김한량 디지털 공방 제작".
- 이전 학년도: "보관·조회 전용" 상시 표시.
- 창 크기에 맞춰 가로·세로 채움. 최소 1366×768·125%. 세로 긴 화면은 남는 높이를 편집 칸에, 좁으면 3단→결과 아래로.

## 2. 첫 실행 마법사

```
시작 설정   ① 연결 → ② 담당 → ③ 명렬 → ④ 일정·완료
```
- ① OpenRouter 키(필수), 가입·발급 안내, [연결 확인]. CLOVA는 "스캔 PDF 가져올 때 설정" 안내만.
- ② 학년도, 담임/비담임 큰 카드 2개, 담임이면 학년·반, 과목(학기)·동아리 추가.
- ③ 묶음별 [붙여넣기][xlsx], 나중에 등록 허용, 준비 상태 요약.
- ④ 일정(건너뛰기 가능), 미등록 명렬 바로 가기 → 현황판.

## 3. 현황판

```
📅 D-3 자율·진로 마감(12/10) · D-10 세특 마감(12/17) · +2개 [관리]
세특 학기 보기 [1학기|2학기]   * 담임 항목·동아리는 연간
[2-3 담임반 30명 · 마감 54/90] [공통수학1 120명 · 마감 40] [과학탐구 24명 · 마감 5]
다음 할 일: [명렬 등록 1곳] [매칭 대기 2묶음] [최종안 검토 8건]
──────────────────────────────────────────────────────
담임: 학번 | 이름 | 자율(연간) | 진로(연간) | 행특(연간) | 내 과목·동아리
과목·동아리: 반·학년·상태 필터, 진행 막대, 학번·이름 | 상태 | 기록 수 | 최종안 B | 확인 사항
상태: ○ 기록 없음 / ◐ 입력 중 / ◑ 최종안 있음 / ● 마감 (색+아이콘+글자)
```
- 행 클릭 → 학생 편집 화면. 빈 명렬이면 [명렬 등록]→[자료 가져오기] 안내.

## 5. 자료 인박스

```
┌ 묶음 목록 ──────────┬ 새 자료 묶음: [진로 학습지 11월]  대상 명렬[2-3▾] 보낼 항목[진로·연간▾] ┐
│ [+자료 가져오기]    │ ① 가져오기 → ② 학생 매칭 → ③ AI 정제(선택) → ④ 보내기 검토          │
│ 진로 학습지 매칭 대기│                                                                  │
│ 독서 기록 보내기 대기│  (단계 본문)                                                      │
│ [보내기 완료 이력]   │                                              [이전] [다음]       │
└─────────────────────┴──────────────────────────────────────────────────────────────────┘
```
- ① 입력 형식 [스캔 PDF|xlsx|붙여넣기|직접 입력] × 기록 구성 [여러 학생|한 학생 여러 회차]. PDF는 학생당 쪽수→"31명분 예상". OCR 버튼 위 CLOVA 전송 안내. 붙여넣기는 해석 미리보기(방식 A/B, 원본 셀 | 만들어질 기록, [가로↔세로], 첫 줄 제목 여부).
- ② 매칭: 원본 위치 | 추출값 | 연결할 학생 | 상태(✔확정/추천/!명렬에 없음/제외). 원본 보기, [추천 일괄 확정], [페이지 다시 묶기], [제외+이유]. 확인 필요 0이어야 다음.
- ③ 정제: 모델, 지침|예시(접기), 기록별 [정제] 후보 3개, [AI 정제 건너뛰기].
- ④ 보내기 검토: 항목·태그·날짜·활동명, "30명/32건, 덮어쓰기 없음, 제외 1, 마감 2명→[마감 해제하고 보내기][제외]", [30명에게 32건 보내기] → 완료 링크.

## 6. 항목별 기록 — 학생 편집

```
항목[세특/공통수학1▾] 학생 20301 김OO  ◐ 입력 중   [◀ 이전] [다음 ▶]
┌ 학생 목록(접기) ┬ 누가기록 4건 ─────────────────┬ 최종안·후보 ───────────────┐
│ [검색][필터]    │ □ 1회 3/15 실험 관찰 [탐구]     │ ✔ 최종안: (없음) [직접 수정] │
│ ◐ 김OO          │   출처: 실험 묶음  [이 건 정제][⋮]│ 후보1 🔒 / 후보2 / 후보3 [정보]│
│ ◑ 이OO          │ □ 2회 4/02 발표 [발표]          │ 1480/1500B (초과 시 빨강)     │
│ ● 박OO          │ [+누가기록] [이미 쓴 생기부 넣기] │ [최종안으로 채택] [● 마감]    │
├─────────────────┴────────────────────────────────┴──────────────────────────────┤
│ 선택한 기록 2건: [종합하기] [태그 일괄 지정] [다른 항목으로 이동]                   │

```
- 종합하기 → 종합 설정 창(기록 | 비중(자동 길이 비례, 회색) | 예상 B, 합계 검사, 성취기준·수준, 모델, 지침|예시).
- 이동 → 문단 선택 창(도착 항목은 학생이 속한 곳만, 실행 후 [되돌리기]).
- 마감 상태면 편집 버튼 비활성 + [마감 해제].

- 설정 탭: [연결·모델(4칸, 학습 차단)] [역할·학년도] [분량·일정] [프롬프트(항목×작업, 지침|예시, 기본값 되돌리기)] [백업·자료(지금 백업, 복원, 학년도 자료 삭제)] [키 초기화].
