# 태그별 기록 화면 설계안 (v0.16 초안)

## 목적
- '항목별 기록'은 담당(슬롯) 하나 → 학생 한 명씩 보는 화면이다.
- '태그별 기록'은 **태그 하나를 고르면 그 태그가 붙은 기록을 가진 학생 전부**가 한 화면에 나오고, 그 자리에서 기록을 바로 고치는 화면이다.
  - 예: '독서' 태그 → 진로·자율·세특·동아리 어디에 있든 독서 관련 기록을 모아 표현을 맞추고 고친다.

## 메뉴
- 왼쪽 메뉴 '📝 항목별 기록' 바로 아래 '🏷️ 태그별 기록'을 둔다.
- 도움말 순서도 같은 위치에 넣는다.

## 화면 배치

```
┌ 태그별 기록 ───────────────────────────────────────────────────────────────┐
│ [반·수업 ▼ 전체] [항목 ▼ 전체] [상태 ▼ 마감 포함] [이름·학번 찾기____]  기록 23건 · 학생 12명 │
├──────────────┬─────────────────────────────────────────────────────────────┤
│ 태그          │ ▾ 2학년 3반  (학생 5명 · 기록 9건)                           │
│ ● 독서  23    │ ┌ 20301 김철수 ──────────────────────────── [항목별 기록에서 열기] ┐
│   탐구  11    │ │ [진로 · 2학년 3반]  3회 · 2026-04-02 · 독서 토론               │
│   발표   4    │ │ ┌──────────────────────────────────────────────┐ 312B   │
│   협업   0    │ │ │ 내용 (바로 고침, 칸을 벗어나면 저장)                 │        │
│ ───────      │ │ └──────────────────────────────────────────────┘        │
│   태그 없음 40 │ │ 태그: [독서×][탐구×][+]                       저장됨 ✓     │
│              │ │ [세특 · 공통수학1(1학기) · 공통수학 A반] 1회 · …             │
│ (반 필터에     │ │ ● 마감됨 — 고치려면 항목별 기록에서 마감 해제   (읽기 전용)   │
│  맞춰 숫자    │ └──────────────────────────────────────────────────────────┘
│  다시 셈)     │ ▾ 공통수학 A반 …                                              │
└──────────────┴─────────────────────────────────────────────────────────────┘
```

### 왼쪽: 태그 목록 (학생 목록 대신)
- 태그마다 '기록 수'를 보인다. 위쪽 반·항목 필터를 바꾸면 그 범위로 다시 센다.
- 맨 아래 **'태그 없음'**: 태그가 하나도 없는 기록. 태그를 정리할 때 쓴다.
- 0건 태그는 흐리게 두되 고를 수 있다(빈 화면 안내).
- 고른 태그는 기억해 둔다(다음에 열면 그 태그).

### 위쪽 필터 줄
1. **반·수업**: '전체' / 학년-반('2학년 3반') / 선택과목의 수업('공통수학 A반').
   - 기준은 항목별 기록 학생 목록과 같다(groupOf): 과목 기록이고 그 학생에게 수업(section)이 있으면 수업으로, 아니면 학생의 학년-반으로.
   - 목록에는 실제로 기록이 있는 반·수업만 나온다.
2. **항목**: 전체 / 자율 / 진로 / 행특 / 세특 / 동아리. 세특·동아리는 담당별로 펼쳐 고를 수 있다(예: 세특 · 공통수학1).
3. **상태**: 마감 포함(기본) / 마감 빼고 / 마감만.
4. **찾기**: 이름·학번·내용 글자.
- 필터는 바꾸는 즉시 반영하고, '필터 지우기' 링크를 둔다.

### 가운데: 기록 목록
- **반·수업 묶음 → 학생 → 기록** 순서로 쌓는다. 묶음 상자는 학생 목록과 같은 묶음 색(GROUP_COLORS)을 쓴다. 묶음은 접을 수 있다.
- 학생 카드: 학번·이름, 그 학생의 해당 태그 기록 수, [항목별 기록에서 열기](그 담당·학생으로 바로 이동).
- 기록 줄마다 **어디의 기록인지 배지**를 맨 앞에 둔다: `진로 · 2학년 3반`, `세특 · 공통수학1(1학기)`, `동아리 · 로봇부`.
  - 항목마다 배지 모양을 다르게 한다(아이콘 + 글자). 색은 상태 색(초록·파랑·노랑·회색)과 겹치지 않게 테두리 위주로 쓴다.
- 기록 머리: 회차 · 날짜 · 활동명 · 기존 완성문 여부.
- **내용은 바로 고친다**: 글상자. 칸을 벗어나거나 Ctrl+S로 저장. 바이트 수 표시.
  - 저장 표시: '저장 중…' → '저장됨 ✓'. 실패하면 빨간 글씨로 남기고 글은 지우지 않는다.
  - 저장하지 않은 채 태그·필터·메뉴를 바꾸면 기존 '저장하지 않은 내용' 확인(leaveOk)을 쓴다.
- 날짜·활동명은 [더보기]를 누르면 고칠 수 있게 펼친다(평소에는 글자로만).
- 태그 칩: × 로 빼고 [+]로 더한다. 지금 고른 태그를 빼면 그 기록은 목록에서 바로 사라지지 않고 흐리게 남아 '되돌리기'를 보인다(다시 불러올 때 빠짐).
- **마감된 학생의 기록**: 파란 '마감' 표시, 글상자 읽기 전용. 항목별 기록으로 가는 링크로 해제를 안내한다.
- 고친 기록의 학생에게 최종안이 있으면 '최종안 다시 확인 필요'(기존 stale 표시)를 노랗게 보인다.
- 기록이 많을 때: 처음 100건만 그리고 [더 보기]. 묶음 접기로 줄인다.

### 여러 건 한꺼번에
- 기록마다 체크박스. 선택한 기록에 [태그 더하기] / [태그 빼기] (기존 tag_records 사용).
- 선택한 기록으로 AI 정제 같은 일괄 AI 작업은 이번에는 넣지 않는다(항목별·일괄 종합에서 한다).

## 상태 색 (앱 전체 규칙과 같게)
- 미입력 회색 / 입력 완료 초록 / 마감 파랑 / 입력 중·확인 필요 노랑.
- 이 화면의 '상태'는 기록이 속한 학생·항목의 상태(최종안 있음·마감 등)를 그대로 쓴다.

## 백엔드
- `api.tag_view(tag_id, filters)` — tag_id=0이면 '태그 없음'.
  - 돌려줌: 기록 목록(id, group_id, item, 담당 이름, 학기, 학생 학번·이름·학년·반·번호·section, kind, seq, date, title, content, bytes, tags, 학생·항목 상태(closed/stale/final 여부)), 필터 선택지(있는 반·수업, 있는 항목·담당), 태그별 개수(필터 반영).
  - 비활성 학생(명렬에서 뺀 학생) 기록은 기본으로 숨기고 '비활성 포함' 옵션.
- 고치기는 기존 `update_record`(마감 검사·stale 처리 포함), 태그는 `update_record(tag_ids)`·`tag_records`를 그대로 쓴다.
- 담임 역할이 아니면 자율·진로·행특 담당이 없으므로 항목 필터에서 빠진다(slots 기준).

## 정하지 않은 것 (검토에서 의견 받기)
1. 학생 카드 묶음을 '반 → 학생'으로 할지, '항목(담당) → 학생'으로 바꿔 보는 토글을 둘지.
2. 태그를 여러 개 동시에 고르기(그리고/또는)를 넣을지 — 이번에는 하나만 고르는 안.
3. 같은 학생의 다른 태그 기록(이 태그가 아닌 기록)을 참고로 접어서 보여 줄지.

## 결정 (2026-11-09, Codex 검토 docs/review/codex_tagview_design.md 반영)
- T01: 반·수업 필터를 두 구역으로 나눈다. 학년-반은 그 반 학생의 모든 기록, 수업은 그 과목·학기·수업의 기록만.
- T04: (가) 자동 저장 + 기록별 [되돌리기]. 이 화면에서 처음 고치기 전 값으로 돌아가며, 그 뒤 다른 곳에서 바뀌었거나 마감했으면 서버가 거절한다.
- 나머지(T02·T03·T05~T17)는 Codex 제안대로:
  - 출처 배지·상태·[이 항목에서 열기]는 담당(항목)마다. 저장은 기록별 순서대로, 화면을 연 뒤 바뀐 기록은 덮지 않음(expect).
  - 마감·비활성·보관 학년도 기록은 읽기 전용, 체크 불가. 태그를 뺀 기록은 '다음 조회 때 빠짐' 표시로 자리에 남김.
  - 100건씩 표시(전체/표시 수, 학생별 잘림 안내). 저장 표시는 상태 색(초록·파랑)과 겹치지 않게 회색·노랑·빨강.
  - '태그' 메뉴는 '태그 관리'로. 태그는 하나만 고름. 다른 태그 기록은 보여 주지 않음.
