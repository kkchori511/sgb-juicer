# 생기부 착즙기 레이아웃 초안 (Claude 1차안)

요구사항: `docs/REQUIREMENTS.md`. 참고 화면: 악필교정기(`~/projects/ncloud-pdf-ocr/app/web/`, `docs/SPEC.md`, `docs/design/*.png`).
원칙: **순차 작업이 자연스럽게 이어지는 것**이 최우선. 선생님이 "지금 뭘 해야 하지?"를 고민하지 않게 한다.

## 1. 전체 틀

```
┌ 상단 바 ───────────────────────────────────────────────────────────────┐
│ [🍊 생기부 착즙기 v0.1 β]  2026학년도▾  [1학기|2학기]   이번 작업 0.02 / 잔액 4.80 크레딧 │
├ 왼쪽 메뉴(작업 순서대로) ─┬ 본문 ──────────────────────────────────────┤
│ ① 현황판               │                                            │
│ ② 인박스 (3)           │                                            │
│ ③ 항목별 기록           │                                            │
│    자율 / 진로 / 행특    │                                            │
│    세특: 공통수학1 …     │                                            │
│    동아리: 과학탐구 …    │                                            │
│ ④ 종합·다듬기           │                                            │
│ ⑤ 조회·내보내기         │                                            │
│ ─────────────         │                                            │
│ 명렬 관리 / 태그 / 성취기준 │                                            │
│ 설정 / 유의 사항 / 사용 안내 │                                            │
└───────────────────────┴────────────────────────────────────────────┘
```
- 메뉴 번호 = 작업 순서. 인박스에 처리 안 된 묶음 수 배지.
- 버전 버튼(제목 옆) 클릭 → 문구 팝업.

## 2. 첫 실행: 설정 마법사(단계 표시)

`1 키 → 2 담임/비담임 → 3 학년도·학기 → 4 담당(반/과목/동아리) → 5 명렬 → 6 일정(건너뛰기 가능) → 완료`
- 한 화면에 한 단계, [이전] [다음], 상단에 진행 표시.
- 2단계 담임/비담임은 큰 카드 2개(쓰는 항목 미리보기 포함).
- 4단계: 담임이면 학년·반 입력 + 과목/동아리 추가, 비담임이면 과목/동아리 추가. 과목은 학기 지정.
- 5단계: 4단계에서 만든 묶음마다 명렬 칸(붙여넣기 / xlsx 불러오기). 나중에 해도 됨.
- 완료 → 현황판. 이후 설정 메뉴에서 같은 내용 수정 가능.

## 3. 현황판

```
📅 D-3 자율·진로 마감(12/10) · D-10 세특 마감(12/17) · +2개
[담임 2-3반 ●18 ◐9 ○3] [공통수학1 ●40/120] [동아리:과학탐구 ●5/24]
──────────────────────────────────────────────────────
(선택한 카드의 표 — 담임은 학생×항목, 과목·동아리는 묶음 표 + 필터)
──────────────────────────────────────────────────────
다음 할 일: 인박스에 매칭 안 된 묶음 1개 · 공통수학1 기록 없는 학생 20명
```
- "다음 할 일" 줄: 다음 행동으로 바로 가는 링크.

## 4. 인박스(입력 → 정제 → 매칭 → 보내기, 한 묶음씩 단계 진행)

```
인박스 목록(왼쪽)          | 선택한 묶음(오른쪽)
- 1학기 진로 학습지 (스캔)  | 단계: 1 가져오기 → 2 학생 매칭 → 3 AI 정제 → 4 보낼 곳 → 5 보내기
- 독서 기록 (붙여넣기)      |
[+ 새 묶음]                |
```
- 새 묶음: 스캔 PDF / xlsx / 붙여넣기 / 회차 누가기록 중 선택.
- 2 학생 매칭: 학번·이름 표. 확정 안 된 행 노랑, 명렬 후보 드롭다운. 모두 확정돼야 다음 단계 활성화.
- 3 AI 정제: 지침/예시 좌우, 모델 선택, 결과 3개 보관.
- 4 보낼 곳: 항목 + 태그 + 날짜/활동명.
- 붙여넣기 미리보기(방식 A/B)는 1단계 안에서.

## 5. 항목별 기록(학생 목록 + 기록 카드)

```
학생 목록(왼쪽, 상태 아이콘) | 학생 기록(가운데)                      | 결과(오른쪽)
● 20301 김OO               | [태그▾] 1회 3/15 독서 … [비중 30%] ⋮이동 | 결과1🔒 결과2 결과3
◐ 20302 이OO               | [태그▾] 2회 4/02 실험 … [비중 70%]       | 실제 1480/1500B
                          | [+기록] [이미 쓴 생기부 넣기]            | [□ 마감]
```
- 기록 카드에서 문단 선택 → 이동(담임 항목 간).
- 위쪽에 [이 기록만 정제] [선택 기록 종합] 버튼.

## 6. 종합·다듬기

- 항목 단위로 여러 학생 일괄 종합(체크한 학생), 진행 창 + [중지](악필교정기 방식).

## 7. 조회·내보내기

- 항목 선택 → 표(학번·이름·최종안·바이트) → [클립보드 복사] [xlsx 저장].
