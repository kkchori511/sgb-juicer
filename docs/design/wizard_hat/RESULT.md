# 마법사 모자 아이콘 결과

[이 SVG](wizard_hat.svg)는 푸른 인디고 고깔, 둥글고 넓은 챙, 노란 별 하나로 구성했습니다. 16~18px에서 모양이 복잡해지지 않도록 작은 별이나 장식 띠는 생략했습니다.

- 파일: `docs/design/wizard_hat/wizard_hat.svg`
- 규격: `viewBox="0 0 24 24"`, 기본 크기 24×24, 바깥 배경 투명.
- 색: 고깔 `#4f63df`, 챙 `#3b5bdb`, 테두리 `#3048b5`, 별 `#fcc419`.
- 선: 문서 형식 아이콘과 같은 1.5 단위 테두리와 둥근 모서리 처리로 느낌을 맞췄습니다.
- 구조: 글자 없이 패스 3개만 사용했습니다. 외부 파일·폰트·이미지·스크립트 참조가 없습니다.

특정 회사의 캐릭터나 로고를 참조하지 않고 일반적인 고깔·챙·별을 직접 구성했습니다.

[preview.png](preview.png)에 16·24·48px 크기를 담았습니다. 각 행은 흰 바탕과 앱의 실제 `--ai-soft` 색인 연보라 `#f1eaff` 바탕을 나란히 보여 줍니다. Mac AppKit으로 SVG를 직접 렌더링하여 고깔·챙·별의 식별을 확인했습니다. 16px에서는 별이 작은 노란 포인트로 보이며, 24·48px에서는 별 모양이 더 뚜렷합니다. Windows WebView2에서의 실화면 확인은 하지 않았습니다.

앱 파일은 수정하지 않았습니다. Chrome 실행이나 텔레그램 등 외부 전송도 하지 않았습니다.
