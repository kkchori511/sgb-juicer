# 생기부 착즙기 요구사항 정리 (2026-11-07 대화 기준)

학기말 학교생활기록부(생기부) 작성에 AI 도움을 받아 초안을 쓰거나 작성된 내용을 다듬는 Windows 앱.
참고 앱: 악필교정기(`~/projects/ncloud-pdf-ocr`, docs/SPEC.md). 설정·키·OCR·OpenRouter·레이아웃·입력 형태는 악필교정기를 기본으로 차용한다.

## A. 기본·배포

- A1. 이름 "생기부 착즙기". Windows exe (Python 3.12 + pywebview + PyInstaller onefile, GitHub Actions Windows 빌드) — 악필교정기와 같은 구성.
- A2. 모든 기능 베타. 버전 0.1부터, 모든 기능이 들어가기 전까지 1.0 미만.
- A3. GitHub에서 새 버전을 올리면 앱이 자동 업데이트(GitHub Release 확인 → 내려받아 교체).
- A4. 상단에 앱 이름 버튼([얼굴 아이콘] 생기부 착즙기 v버전 베타). 버튼 클릭 시 "선생님의 자료 한 방울까지 생기부에 넣겠습니다." / "Made by 김한량 디지털 공방". 상단 가운데에 저장 상태 버튼(저장됨 + 마지막 저장 월·일(요일) 시:분:초 초록 · 저장 중… · 저장 안 됨 빨강). 마우스를 올리면 '클릭하면 수동저장 됩니다.', 누르면 남은 저장을 마치고 자료 파일에 기록(백업은 만들지 않음).
- A5. 기본 기능 설명(사용 안내)은 나중에 추가.

## B. 보안·키·AI 전송

- B1. 키·설정은 악필교정기와 동일: exe 옆 설정 JSON 평문 자동 저장, [키 초기화]. API 키는 본인 관리.
- B2. OpenRouter 키 필수(없으면 처음에 설정 화면). CLOVA 키는 OCR 쓸 때만 필요 — 네이버 클라우드 플랫폼 가입·API 설정 안내(악필교정기 가입 안내 탭 재사용).
- B3. AI(OpenRouter)에는 학번·이름 등 인적사항을 보내지 않고 내용만 보낸다. 학생 연결은 앱이 관리. OCR 원문에서 학번·이름 줄은 앱이 제거, 붙여넣기·xlsx는 학번·이름 열/줄을 빼고 내용 셀만 전송. 성취수준(A~E)처럼 비식별 정보만 함께 보낼 수 있음. 본문 속 이름 치환·전송 내용 미리보기는 하지 않는다(본문에 이름이 들어갈 일이 거의 없음).
- B4. OpenRouter 학습 차단 옵션 켜기/끄기(기본 꺼짐). 켜면 `provider: {"data_collection":"deny","zdr":true}`. 쓸 수 있는 제공자가 없어 실패하면 원인 안내.
- B5. 사용량: 상단에 "이번 작업 N 크레딧 사용 / 잔액 N 크레딧"(악필교정기와 동일).
- B6. 모델 4칸 등록, 작업 때 선택. 1번 칸 기본값 `google/gemma-4-31b-it:free`. 무료 모델은 학습 차단 켜면 실패 가능·속도 제한 안내.
- B7. **유의 사항 및 안내문** 메뉴 페이지:
  - CLOVA OCR에는 스캔 이미지가 그대로 전송(손글씨 이름·학번 포함) — 거슬리면 스캔 전 인적사항을 직접 마스킹해야 함.
  - OpenRouter에는 내용만 전송, 학습 차단 옵션 있음, 계정 설정 https://openrouter.ai/settings/privacy 권장.
  - 키는 설정 파일에 평문 저장, 공용 PC는 사용 후 초기화, 본인 키만 사용.

## C. 초기 환경 설정

- C1. 처음에 **담임 / 비담임** 선택. 결과에 따라 메뉴·입력창·항목이 구성됨.
  - 담임 전용: 자율활동, 진로활동, 행동특성 및 종합의견
  - 공용: 과목별 세부능력 및 특기사항(세특), 동아리활동
- C2. 과목·동아리 여러 개 등록, 각각 명렬.
- C3. 학년도 단위 데이터. 새 학년도 시작 시 이전 학년도는 보관·조회 전용.
- C4. 과목은 학기 단위(과목마다 1학기/2학기 지정, 학기별 과목명은 서로 다름. 예: 공통수학1, 공통수학2). 담임 항목·동아리는 1년 단위(보통 2학기 말 정리).
- C5. 3학년 예외: 담임 항목은 3학년 반이면 1학기 말 마감, 동아리는 **3학년 학생에게만** 1학기 마감 적용.
- C6. 목표 분량(바이트, 한글 3·그 외 1): 행특 900, 나머지 1500. 항목별 수정 가능.
- C7. 생기부 일정 등록(날짜·내용) → 현황판 맨 윗줄에 날짜순·D-day 표시. 7일 이내 주황, 당일 빨강. 지난 일정은 윗줄에서 빼고 설정에서만 회색. 넘치면 "+N개".
- C8. 과목별 성취기준·성취수준: 필요한 과목만 직접 입력(붙여넣기, 텍스트 PDF, hwpx). 3단계 또는 5단계. 사용 여부는 작성할 때마다 선택.

## D. 명렬·학생

- D1. 명렬 3종: 학급(같은 학년·반), 과목별(같은 학년, 반 섞임), 동아리별(학년·반 섞임). 학번이 학생 구분 기준.
- D2. 입력: 클립보드에서 추가(엑셀 범위 복사, 다른 범위로 또 누르면 이어 붙음, 창 안 Ctrl+V도 됨), 파일 추가(xlsx·csv 여러 개 한꺼번에), 한 줄 추가. 세 방법을 섞어 계속 이어서 넣고, [마지막 추가 취소]로 직전 추가분만 뺀다. 반영은 기존 명렬에 더한다(이미 있는 학생은 정보만 갱신). 열을 알아보지 못한 원본은 열 연결을 묻는다.
- D2-1. 명렬에서는 성취수준을 받지 않는다. 성취수준은 세특에서 기록이 없는 학생을 성취기준으로 생성할 때(학생 화면·일괄 종합)만 고른다.
- D2-2. 전입: [학생 한 명 추가]로 한 줄씩. 전출: 선택 학생을 비활성화(기록 보존) 또는 삭제(기록·후보·최종안도 지움, 자동 백업) 중 선택, 이 소속만/모든 소속. 비활성 학생은 명렬에서 붉은 글씨·'비활성' 표시로 기본 표시.
- D2-4. 명렬 칸 순서는 학년·반·번호·이름(학번은 맨 뒤 참고). 붙여넣기는 먼저 형태를 묻는다: [학년·반·번호·이름] → 앞 3줄 미리보기로 순서 확인(아니면 열 직접 고르기), 3열이면 반·번호·이름(학년: 담임반은 반 학년, 과목·동아리는 입력) / [학번·이름] → 자동 분류(5자리 학번을 학년·반·번호로). 파일은 머리글로 알아보면 바로 넣고 아니면 같은 질문.
- D2-5. 명렬 복사: [다른 담당 명렬 가져오기]로 다른 담당의 활성 학생(비활성·전출 제외)을 명렬 입력에 한 묶음으로 넣는다(1학기 → 2학기).
- D2-6. 체크 칸은 26px(기본의 두 배), 체크 칸이 든 칸을 눌러도 체크. 체크한 줄은 연한 초록+왼쪽 초록 선(비활성 학생의 빨간 글씨는 유지).
- D2-7. 이미 쓴 생기부 일괄 넣기: 이름·내용 두 칸만 있으면 이름으로 연결(학번·반/번호는 확인용). NEIS 공식 업로드 파일(학년도·학기·학생개인번호·과목·과목코드·반/번호·성명·학적변동 구분·내용)의 머리글을 알아보고, 반/번호 `1/1`·`1반 1번`을 읽는다. `1-1`은 머리글이 없으면 반-번호·학년-반 둘 다 명렬과 맞춰 본다. 상태: 확정(초록)·추천(노랑, [추천 모두 확정] 또는 줄마다 확정해야 넣음)·확인 필요(빨강, 학생을 고르거나 ✕). 학적변동 값은 알림.
- D2-8. 줄 순서 바꾸기: ⠿ 손잡이 끌기 + ▲▼ 버튼. 이미 쓴 생기부 일괄 넣기, 자료 인박스 매칭 표(저장), 항목별 기록의 누가기록(저장, 종합 때 AI에 보내는 순서). 마감·보낸 묶음·필터 중에는 끔.
- D2-3. 마우스 뒤로·앞으로 버튼(Alt+←/→)으로 메뉴 화면을 오간 순서대로 이동(열린 창이 있으면 이동하지 않음).
- D3. 학생별 성취수준을 명렬(과목)에 넣을 수 있음.
- D4. 학생 비활성화(소속별, 전출은 모든 소속 일괄 — J6): 회색 표시, 기록 보관, 내보내기·매칭 후보·일괄 보내기·일괄 종합에서 제외. 다시 활성화 가능.

## E. 입력: 인박스

- E1. 어떤 활동이든 인박스로 입력: 스캔 PDF(CLOVA OCR), xlsx, 붙여넣기.
- E2. 스캔 PDF: 악필교정기 방식(학생당 페이지 수, 10페이지 분할 OCR). OCR 결과에서 학번·이름을 **AI 없이 규칙으로** 추출 → 정렬. 불완전하면 직접 수정하거나 명렬과 연결(비슷한 이름 후보 추천).
- E3. 인박스에서 AI 정제·수정(내용만 전송).
- E4. 정제한 내용을 항목(자율/진로/행특/과목 세특/동아리)의 해당 학생들에게 **한꺼번에** 보내기.
- E5. 매칭 안 된 학생이 하나라도 있으면 경고, 보내기 불가. 매칭 확정 후에만 보냄.
- E6. 회차 누가기록: 한 학생에 날짜·회차별 여러 건. 직접 입력 또는 엑셀 드래그 붙여넣기(셀마다 한 건으로 분리).
- E7. 붙여넣기 미리보기:
  - 방식 A(한 학생에게): 비어 있지 않은 셀마다 한 건, 행 우선/열 우선 선택.
  - 방식 B(여러 학생): 학생이 행/열 선택, 학번·이름 줄 자동 탐지, 첫 줄이 날짜·회차면 이름으로 사용(아니면 1회, 2회…), 매칭 규칙은 E5.
  - 공통: 빈 셀 건너뜀, 셀이 어느 학생 몇 번째 기록인지 색 표시, [가로↔세로 바꾸기].
- E8. 이미 작성된 생기부는 인박스를 거치지 않고 항목의 학생에게 바로 넣기(붙여넣기·xlsx). 바로 다듬거나 다른 기록과 함께 종합.

## F. 항목·기록

- F1. 항목 안에서 학생마다 받은 기록을 합치지 않고 한 건씩 누가기록으로 보관.
- F2. 항목에서 학생을 누르면 기록이 구분되어 나열.
- F3. 태그: 태그 관리 화면에서 만든 목록에서 고름(통일성). 입력할 때 지정 또는 여러 기록 골라 일괄 지정. 한 기록에 여러 개.
- F4. 기록 이동: 다른 항목으로 보낼 수 있음. 담임 항목(자율·진로·행특) 사이는 **문단 단위** 이동, 동시 기록 불가. 이동 후 분량 초과 시 표시.
- F5. 진행 상태: 기록 없음(자동, 회색) / 입력 중(자동, 노랑) / 최종안 있음(자동, 파랑) / 마감(체크박스, 초록). 마감하면 편집 잠금, 풀면 다시 편집.

## G. AI 처리

- G1. 기록 한 건 정제, 또는 여러 기록 종합 정제.
- G2. 종합 시 기록별 비중(%) = 결과 분량 비율. 예: 1500바이트에서 60%면 약 900바이트. 비중 없는 기록은 남은 비율을 기록 길이 비례로 분배(J14). 합계 100% 검사는 옵션(켜고 끄기).
- G3. 변환 결과는 최근 3개 보관(잠금 포함 3개). 새 결과가 오면 잠기지 않은 가장 오래된 것 삭제. 3개 모두 잠겼으면 경고하고 실행 안 함.
- G4. 세특: 성취기준 사용 선택 시 기록을 성취기준 관점에서 해석. 기록 없는 학생은 성취기준만으로 생성("기록 없음, 성취기준으로 생성" 표시), 이때 성취수준을 묻고 명렬 값이 있으면 기본으로 채움. 성취수준별로 문장 다르게.
- G5. 프롬프트: 항목별 기본 프롬프트 제공, 정제·다듬기·종합 모두 개인 커스텀, 로컬 저장, 기본값 되돌리기.
- G6. 모든 프롬프트 칸 옆에 **예시 칸**(왼쪽 지침, 오른쪽 예시). 예시가 있으면 항상 함께 보내고 반드시 따르도록 지시.
- G7. 기본 프롬프트 내용은 사용자가 나중에 줄 예시안으로 함께 확정(개발 중엔 임시값).

## H. 현황판

- H1. 초기 설정 후 첫 화면은 현황판.
- H2. 맨 윗줄: 생기부 일정(C7).
- H3. [1학기 | 2학기] 전환: 세특은 선택 학기 과목만, 담임 항목·동아리는 항상 표시.
- H4. 요약 카드 줄: 담임반·과목·동아리 카드(상태별 수). 카드 누르면 아래 표 전환.
- H5. 담임반: 학생×항목 표(자율·진로·행특 | 내가 맡은 과목·동아리 공용 칸).
- H6. 과목·동아리: 묶음별 표(학번·이름·상태·기록 수·바이트), 반·학년·상태 필터, 진행 막대. 행 클릭 → 그 학생의 해당 항목 화면.

## I. 조회·내보내기

- I1. 항목별 조회(NEIS에 항목별 입력하므로).
- I2. 내보내기는 xlsx와 클립보드 복사 둘 다, 셀 병합 없이 한 행 한 학생. 칸 순서: 학년·반·번호·이름·상태·최종안·바이트.
- I3. 비활성화 학생 제외.

## J. UX·세부 규칙 결정 (Codex 검토 후 확정, 2026-11-08)

화면 구성은 `docs/design/LAYOUT.md`. 검토 기록은 `docs/design/codex_ux_review.md`.

- J1. 메뉴 번호 없음. 순차 안내는 현황판 "다음 할 일"과 처리 중인 묶음 안의 단계 번호가 맡는다. 왼쪽 메뉴는 접기/펼치기(접으면 본문 확장, 상태 기억).
- J2. 화면은 창 크기에 맞춰 가로·세로 모두 채운다. 최소 1366×768·배율 125%에서 깨지지 않게. 첫 실행 최대화, 이후 마지막 창 크기·위치 기억. 세로로 긴 화면(16:20 등)은 남는 높이를 기록·지침·결과 칸에 쓰고, 3단이 좁아지면 결과 칸을 아래로.
- J3. 학기 전환은 앱 전체가 아니라 현황판의 "세특 학기 보기"만. 담임 항목·동아리에는 "연간" 표시.
- J4. 첫 실행 마법사 4단계: ① 연결(OpenRouter 필수, [연결 확인]) → ② 담당(학년도, 담임/비담임, 반, 과목·학기, 동아리) → ③ 명렬(나중에 등록 허용, 준비 상태 요약) → ④ 일정·완료(미등록 명렬 바로 가기). 모델·분량·성취기준·프롬프트는 기본값으로 시작.
- J5. 명렬: 열 자동 연결(수정 가능), 학번 5자리로 학년·반 계산(수정 가능), 중복·빈칸·이름 불일치 해결 후 반영. 학번이 같으면 같은 학생(학년도별). 인박스에서 오면 [반영하고 매칭으로 돌아가기].
- J6. 비활성화는 소속별. [모든 소속에서 비활성화(전출)] 체크박스.
- J7. 현황판: 카드 숫자에 단위("30명 · 마감 54/90항목"), 다음 할 일(명렬 미등록→매칭 대기→보내기 대기→최종안 검토→마감·내보내기), 확인 사항 열("채택 후 기록 추가됨"), 빈 상태 안내, 상태는 색+아이콘+글자.
- J8. 인박스: 새 묶음에서 대상 명렬·보낼 항목 먼저 지정 → ① 가져오기(입력 형식과 기록 구성 따로 선택, OCR 직전 CLOVA 전송 안내) → ② 매칭(전원 확정해야 다음) → ③ AI 정제(선택, 건너뛰기 가능, 기록 한 건씩, 고른 후보만 보냄) → ④ 보내기 검토(요약 확인 후 전송, 완료 후 링크). 묶음 상태 표시, 중간 저장·재개.
- J9. 매칭: 학번+이름 일치는 자동 확정, 이름 유사는 "추천"(선생님 확정). 원본 이미지·OCR 글자 대조. [페이지 다시 묶기]. 같은 학생 여러 건은 정상, 중복은 "의심" 표시. 행 [제외]+이유 허용 — 제외 행은 인박스에 남고 보내기 검토에 "제외 N건" 표시.
- J10. 학생 편집 화면: 학생 목록(접기) | 누가기록 | 최종안·후보 3단. 이전/다음 학생(필터 안에서). 기록 카드에 회차·날짜·활동명·태그·출처, [이 건 정제], ⋮(수정·삭제·이동). 기존 완성문 표시. 비중은 종합 설정 창에서만. 필터·선택·스크롤 기억.
- J11. 후보 3칸은 단위별로 따로: 기록 한 건의 정제 후보 3개, 학생×항목의 종합·다듬기 후보 3개. **최종안은 후보와 별도 칸**: 채택 시 복사, 직접 수정 가능(후보 칸 미사용), 기존 완성문도 바로 채택 가능. 용어 고정: 🔒 보관 잠금 / ✔ 최종안으로 채택 / ● 마감.
- J12. 마감: 최종안 없으면 불가. 분량 초과는 빨간 "NB 초과" 표시만 하고 마감은 허용. 마감 시 기록 추가·수정·삭제·이동·AI 실행·최종안·태그 변경 잠금, 조회·복사·내보내기 허용. [마감 해제]는 확인 없이. 인박스 보내기 대상에 마감 학생이 있으면 [마감 해제하고 보내기]/[제외] 선택. 일괄 종합은 마감 학생 자동 제외·알림.
- J13. 문단 이동: 누가기록 전체 또는 문단(빈 줄·줄바꿈 기준) 선택. 도착 항목에 새 기록(날짜·활동명·태그·"OO에서 이동" 출처), 출발에서 삭제(비면 기록 삭제). 담임 항목 사이 + 그 학생이 속한 과목·동아리로 가능. 최종안은 옮기지 않고 양쪽에 "채택 후 기록 변경됨" 경고. 직후 [되돌리기]. 마감 항목이면 불가.
- J14. 비중: 고른 기록만 계산. **기본은 기록 길이(바이트) 비례**, 일부만 지정하면 나머지는 비운 기록끼리 길이 비례. 자동 비율은 회색 표시. 숫자 아님·음수 차단. 합계 검사 ON: 지정값 합이 100% 초과 등으로 100%가 안 되면 실행 불가. OFF: 비율대로 정규화하고 실제 적용 비율 표시. "목표 비율이며 정확히 맞지는 않음" 설명.
- J15. 일괄 종합: 학생별 길이 비례 자동, 학생 화면에서 지정한 비중 우선. 실행 전 대상 요약(잠김 3개·마감 제외, 기록 없음은 성취기준 생성+수준 선택 필요). 진행 창(완료/실패/대기, 경과, 중지), 실패만 재실행. 결과는 학생 화면과 같은 후보 3칸.
- J16. 내보내기: 한 번에 한 항목·담당. 기본 "모두", 옵션 "마감만". 미마감은 화면 노란 행+라벨, xlsx "상태" 열+노란 배경, 학번·이름·최종안 복사 시 상태 열 포함. 최종안 문장에는 표시 넣지 않음. 최종안 없는 학생은 행 넣고 빈칸. 복사 범위 [학번·이름·최종안 | 최종안만], 머리글 포함/제외. xlsx·복사·미리보기는 같은 대상·순서. 내보내기로 상태 바꾸지 않음. 셀 안 줄바꿈 유지(NEIS 붙여넣기는 실환경 확인 필요).
- J17. 저장: exe 옆 `생기부착즙기_데이터` 폴더. 학생 자료는 학년도별 SQLite, 스캔 PDF·OCR 결과도 보관. 변경 즉시 자동 저장, 상단 "저장됨 HH:MM". 실행 시 하루 1회 자동 백업 최근 7개, [지금 백업]/[백업에서 복원]. 폴더째 복사로 이동 가능.
- J18. 보내기는 전부 성공 또는 전부 취소. 보낸 묶음은 "보내기 완료"로 잠그고 재전송 시 경고.
- J19. 자동 업데이트: 실행 시 확인·알림, [지금 업데이트] → 백업 → 내려받아 exe 교체. 새 버전을 자동으로 켜지 않고(학교 보안 프로그램) "종료 후 다시 시작" 안내와 [지금 종료]·[나중에], 보안 프로그램 예외 등록 안내. 작업 중 교체 안 함.
- J20. [키 초기화]는 키만. 자료 삭제는 별도 [이 학년도 자료 삭제] + 학년도 이름 입력 확인.
- J21. 유의 사항 추가: 데이터 폴더에 학생 자료가 평문 저장되므로 배포 시 exe만 줄 것.
- J22. 기타: 이번 작업 사용량은 앱 실행 후 누적, 잔액 조회 실패는 "확인 불가". 역할 변경은 자료 숨김(삭제 X)+영향 미리보기, 역할은 학년도별. 태그 이름 변경은 전체 반영, 사용 중 삭제는 "N건 사용 중" 경고 후 제거. 목표 분량은 항목 기본값+과목·동아리별 조정, 변경은 표시만 즉시 반영. 결과마다 모델·지침·성취수준·근거 기록 저장([정보]). 3/5단계 변경 시 범위 밖 수준 노랑. 학습 차단 자동 해제 안 함, 오류 유형 구분+바로 가기. 일정·3학년 1학기 마감은 표시만, 자동 마감 없음.
