## 이어서 할 수 있는 일 (사용자가 꺼낼 때)

- 도움말 '착즙기 사용 매뉴얼': 메뉴 역할 세 갈래로 쓴다 — 자료 Inbox(여러 학생 자료 나눠 넣기), 항목별 기록(한 학생씩), 태그별 기록(같은 종류 일괄 AI 변환).

## 다른 컴퓨터로 넘어가지 않는 것 (Claude 메모 요약)

Claude 메모는 컴퓨터마다 따로라서, 이어 갈 때 필요한 내용을 여기 적어 둔다. 규칙은 `AGENTS.md`에 있다.

- 정해 둔 디자인 기준(2026-11-19):
  - 버튼 색은 용도별 하나: AI 연한 보라(✧), 마감 파랑, 확정 초록, 삭제 빨강, 그 밖의 주 동작 짙은 남색, 보통 흰 바탕. 파일 버튼은 엑셀 초록 / PDF 빨강 / 한글 파랑(테두리 + 연한 바탕 + 형식 아이콘). 마법사는 푸른 보라(인디고) + 파란 별 모자.
  - 결과 상자: AI 결과 보라 점선, 원문·직접 작성 회색 실선, 확정 초록 실선 + `✔ 확정됨`. 결과 제목은 노란 칩.
  - 화면 글의 띄어 쓴 구분 점(` · `)은 ` / `로. 붙여 쓴 나열(`학번·이름`)은 그대로.
  - 같은 줄 버튼은 크기를 맞춘다(보통 40px).
- NEIS 파일: 다운로드 파일에는 `학년` 열이 더 있고, `반/번호`는 `1/1` 한 칸, 학생개인번호는 학번이 아니다, 머리글에 `_x000D_`가 섞여 있다.
- 로딩 창(`app/web/intro.html`) 글자를 바꾸면 작은 글꼴(`app/web/fonts/intro-*.woff2`)을 다시 만들어야 한다(`pyftsubset`로 그 화면 글자만). 로딩 창은 보안 설정(CSP)이 있어 인라인 스크립트와 data 글꼴만 허용한다.

## Windows에서 시작하기

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt pytest
.\.venv\Scripts\python run.py                  # 앱
.\.venv\Scripts\python scripts\demo_mac.py      # 더미 자료 데모(이름은 mac이지만 같은 소스, 실제 자료·크레딧 안 씀)
```

- 테스트는 파일마다 따로 돌린다(한꺼번에 pytest로 돌리면 시험 파일끼리 자료 폴더가 섞여 실패한다):
  `Get-ChildItem tests\test_*.py | % { .\.venv\Scripts\python -m pytest -q $_.FullName }`
  pytest로 오류가 나는 3개(`test_existing_import`, `test_recheck_fixes`, `test_review_fixes`)는 `python tests\<파일>`로 직접 실행해 확인한다.
- Codex 협업(그림·검토)은 herdr 안 같은 작업공간의 Codex 창이 있을 때만 맡긴다. 없으면 사용자에게 열어 달라고 한다.
- 릴리스: 버전(`app/__init__.py`) 올리기 → README 변경 기록 → 커밋 → 데모 띄워 사용자 확인 → 브랜치·태그 push → `gh release create vX --notes-file …`(빌드는 GitHub Actions가 exe를 붙임).
