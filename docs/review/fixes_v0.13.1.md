# v0.13.1 — Codex UX 검토(codex_ux_v013.md) 반영

| 번호 | 처리 |
|---|---|
| U01 | 열을 다시 골라도 표에서 고친 학생·확정·빼기·순서·날짜를 원본 행 번호로 다시 입힘. 내용 열을 바꾸면 고친 내용은 새 열로 바뀌고 알림. 연결 중에는 입력 버튼 잠금, 늦게 온 응답은 버림. 단계 표시(①②③). |
| U02 | 학번과 이름이 다른 학생 → 확인 필요(이름 한 글자 차이는 추천). 학번이 명렬에 없음·반/번호 다름 → 추천. 원본 학번 표시. |
| U03 | [전문 비교]로 지금 최종안과 보낼 글을 펼쳐 봄. 덮어쓰기 확인에 이름 표시, 버튼에 덮어쓰기 인원. 보낸 직후 [되돌리기](그 뒤 고치거나 마감한 학생은 그대로). |
| U04 | 입력·보내기 버튼을 누르는 즉시 잠그고, 요청 번호로 서버에서도 한 번만 적용. |
| U05 | 처리 칸을 체크 상태로 표시(새로 반영/덮어쓰기/이번에는 제외), 조건(최종안 없음/있음)은 아래 줄. 요약에 반영·제외·전체 수. |
| U06 | '마지막으로 추가한 것'으로 이름을 바꾸고, 보낼 글의 제목·추가·수정 시각·바이트 표시. |
| U07 | 여러 개인 학생은 줄에서 보낼 것을 고름. '직접 고르기'는 고르기 전에는 제외. |
| U08 | 최종안과 후보를 따로 접고 제목은 늘 보임. 둘 다 접으면 칸 전체가 막대. 새 후보가 생기면 후보 칸을 펼침. aria-expanded. |
| U09 | 공통 줄 제목에 담당명 + '검색·필터와 관계없이 명렬 전체', 창 제목에도 범위. 학생 칸 제목에 학생 이름. |
| U10 | 이미 쓴 생기부 입력 안내·완료 창에 '아직 최종안이 아님', 이어서 최종안 일괄 보내기 열기. |
| U11 | 날짜: 연도 없는 날짜는 학년도로, 엑셀 일련번호, 달력 검사. 못 읽으면 확인 필요 + 원본 표시 + 줄에서 고치기·[날짜 없이]·한꺼번에 날짜 없이. |
| U12 | 열 선택지 '열 문자 · 머리글 · 예시 2개', 필수는 '(고르세요)', 선택은 '(사용 안 함)'. 버튼 '열·학생 연결 확인 →'. |
| U13 | '원본 행' 번호 고정(엑셀 행 번호와 같음). |
| U14 | 클립보드 표는 붙여넣기 칸에 넣어 두고 알림. 언제나 ① 단계에서 시작. |
| U15 | 날짜 넣기를 끄면 날짜 칸을 숨기고 '날짜 없이 저장', 날짜 있던 기록에서 끄면 지운다고 알림. |

확인: tests 10개 통과(test_existing_import.py에 U02·U03·U04·U06·U11 시험 추가), Playwright(1100×900)로 U01~U15 흐름 확인. Windows 실기·배율별 확인은 하지 않음.
