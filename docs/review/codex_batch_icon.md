# 왼쪽 메뉴 ‘일괄 종합’ 아이콘 검토

## 기능 확인

`app/web/index.html:450–451`의 사용 안내와 `app/web/app.js:4054–4168`의 batch 패널을 확인했다. 담당과 학생들을 고른 뒤, 학생마다 여러 기록을 비중에 따라 AI로 종합하는 기능이다. 기록이 없는 학생은 선택한 성취기준으로 생성할 수도 있다. 결과는 **최종안 후보**로 저장하며 교사가 확인·채택한다. 자동 마감 기능은 아니다.

따라서 메뉴 아이콘은 설정이나 자료 이동보다 **AI로 문장을 만들어 정리하는 작업**을 나타내는 편이 적합하다. 현재 메뉴(`index.html:35–47`)와 비교했으며, 설정은 요청대로 **⚙️ 설정**으로 옮기고 🔧는 제외하는 구성을 전제로 했다.

## 추천 후보

| 순위 | 이모지·메뉴 예시 | 이유 |
|---|---|---|
| 1 | **✨ 일괄 종합** | AI가 기록을 정리해 문장으로 만드는 느낌이 직관적이고, 작은 크기에서도 단순한 별 모양이 다른 메뉴와 잘 구분된다. |
| 2 | **🤖 일괄 종합** | AI 작업임을 가장 직접적으로 알리며, 명렬의 👥와 문서·태그 아이콘들과도 형태가 확실히 다르다. |
| 3 | **🧩 일괄 종합** | 여러 기록 조각을 하나의 글로 종합한다는 뜻에 잘 맞지만, AI 기능이라는 의미는 메뉴 글자가 보완해야 한다. |
| 4 | **💡 일괄 종합** | 전구 형태가 작게 보여도 구분하기 쉽지만, 기록 종합보다 아이디어·도움말 기능으로 읽힐 여지가 있다. |

모두 기존 메뉴 📊📥📝🔖📤👥🏷️📚⚙️📖⚠️와 중복되지 않는다. Windows의 Segoe UI Emoji 표시를 고려해 여러 문자를 결합하는 이모지보다 단순한 단일 이모지를 골랐다. **Windows 실기 렌더링은 확인하지 않았으며**, 특히 얼굴 세부가 있는 🤖보다 윤곽이 단순한 ✨를 우선한다. 최종 적용 시 실제 메뉴 크기와 Windows 배율에서 확인하면 된다.

## 최종 추천

**✨ 일괄 종합 / ⚙️ 설정**을 추천한다. ‘여러 학생’이라는 범위는 메뉴 글자의 ‘일괄’이 설명하고, ✨는 AI로 글을 만들어 정리하는 역할을 보완한다. 다른 메뉴와 형태가 겹치지 않고 설정과의 혼동도 줄인다.

이 보고서만 추가했으며 코드·메뉴 파일은 수정하지 않았다. Chrome 실행·외부 전송·git commit/push는 하지 않았다.
