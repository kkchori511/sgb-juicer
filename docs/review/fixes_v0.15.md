# v0.15.0 — Codex UX 검토(codex_ux_v015.md) 반영

| 번호 | 처리 |
|---|---|
| V01 | AI는 줄을 지울 수 없음: AI가 '머리글'이라 한 줄은 그대로 남기고 목록으로 알림. 보존 검사는 AI 역할과 무관하게 원문 기준(빈칸·A~E 기호 줄·규칙 머리글만 제외). 성공 문구에 검사 범위 표시. |
| V02 | 기록 칸 접기 CSS를 기록·최종안·후보 칸으로 한정 → 학생 묶음을 접어도 제목·펼침 버튼이 남음. |
| V03 | B·D 기호가 아예 없는 A·C·E 입력도 3단계로 인식. 사이가 빈 다른 수준은 '(원문에 내용 없음)'. |
| V04 | 줄 모양과 맞지 않는 AI 답(엉뚱한 label·standard, 잘못된 JSON)은 오류 없이 '확인 필요'로 제자리에 남기고 표시. 정리 모델 선택을 화면에 둠. |
| V05 | 저장에 성공한 뒤에만 편집칸을 정리본으로 바꿈(실패 시 원문·저장 대기 유지). 적용 직후 [정리 전으로 되돌리기]. |
| V06 | 확인 창·안내 문구: '명렬의 학번·이름은 보내지 않음, 본문에 적힌 이름은 그대로 감'. 성취기준 정리는 '원문 줄과 앞뒤 문맥을 보냄, AI는 쓰거나 지우지 않음'. |
| V07 | 인박스 정제 확인에 '원문 유지·행마다 후보 3개 보관, 넘으면 오래된 것 삭제·새 결과 자동 선택' 안내. |
| V08 | 중지 버튼을 처음부터 '다음 건부터 중지'로, 누르면 '지금 건이 끝나면 멈춤'. 진행 막대는 실제 처리 비율 유지. 일괄 종합은 미실행 학생도 '실패·미실행 N명 다시 실행' 대상(완료 학생은 다시 하지 않음). 대기 안내 '보통 수십 초, 느리면 몇 분'. |
| V09 | 진행 창의 실패 목록을 전부 보여 줌(스크롤). 인박스는 실패·미실행 행만 골라 두어 [선택 N건 정제]로 이어서 실행. |
| V10 | 확인 창은 열릴 때 [취소]에 포커스, 닫히면 원래 위치로. 진행 중에는 화면 전체를 inert로 막고 학생 이동 단축키도 무시. aria-modal. |
| V11 | 종합 지침·예시, 성취수준 저장은 [AI 실행]을 승인한 뒤에만(실패하면 실행 안 함). 확인 창에 저장된다는 사실 표시. |
| V12 | 합산 연결 중에는 일반 '목표 분량' 칸을 끄고 이유 표시. 남은 바이트가 0 이하면 종합·다듬기·기존 완성문 다듬기 버튼을 미리 막음. 내보내기 0 목표 보존(`??`). |
| V13 | 2학기·1학기 화면에 '⚠ 합산 초과'(마감했어도 다시 확인). 내보내기 전에 합산 초과 학생 목록 확인. |
| V14 | 학기를 바꾸면 맞지 않게 된 합산 연결을 자동으로 풀고 알림. 계산할 때도 2학기→1학기 관계가 아니면 무시. 1학기 쪽은 연결된 2학기 과목을 모두 표시. |
| V15 | 선택 표시는 상태 색과 겹치지 않게 짙은 회색(▶·◀ 선택됨). 학생 묶음 색에서 파랑·초록 제외. 내보내기 표에 상태 배지(● 마감 파랑·◑ 최종안 초록·○ 없음 회색). 인박스에서 AI 정제를 안 했으면 단계 막대에 '건너뜀'. |
| V16 | 통계 칩이 상태 색을 유지, 마감 칩 추가, '담당 전체 기준·검색어 적용 중(목록 N명)' 표시. |
| V17 | 성취기준을 직접 입력·삭제해 저장되면 왼쪽 과목 목록 색·문구가 바로 바뀜. 공백만 있으면 미입력. |
| V18 | 수업 칸 안내: 비우면 새 학생은 미지정, 기존 학생은 기존 수업 유지. [수업 지정 해제] 버튼을 따로(확인 후). 수업으로 묶이는 규칙 안내. 파일 이름을 수업 이름으로 넣으면 확인 안내. |
| V19 | 검색·필터 중에는 묶음 접기 버튼을 끄고 이유 표시. 검색어로 수업·반 이름도 찾음. |

확인: tests 12개 통과(test_stdformat·test_pair_subject에 V01·V03·V04·V13·V14 시험 추가), Playwright로 V02·V03·V05~V19 화면 흐름 확인. Windows 실기·배율별 확인은 하지 않음.
