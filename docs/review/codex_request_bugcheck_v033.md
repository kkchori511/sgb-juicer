## 할 일

각 메뉴의 **버튼과 작업 흐름이 의도대로 돌아가는지** 코드를 따라가며 버그를 찾아 주세요. 화면 JS의 이벤트 → `api.*` 호출 → Python 처리 → 화면 갱신까지 끝까지 따라갑니다.

1. **화면 ↔ API 짝 맞추기**: `app.js`에서 부르는 `api.이름(...)`·`call('이름', ...)`·`mutate('이름', ...)`·`rawCall('이름', ...)`마다 `api.py`에 같은 이름의 메서드가 있는지, 인자 개수·순서가 맞는지. 없는 메서드, 인자 어긋남을 모두 적기.
2. **id 짝 맞추기**: `app.js`의 `$('id')`가 `index.html`에 있는지(동적으로 만드는 것은 제외). 없는 id 적기.
3. **메뉴별 흐름 점검** (각각 정상 흐름 + 빈 값·취소·마감됨·보관 학년도·권한 없음 같은 경계):
   - 현황판(학기 보기, 2학기 먼저)
   - 자료 인박스(새 묶음 → 원본 넣기 → 학생 짝 → 보내기, 이미 보낸 행)
   - 항목별 기록(기록 추가·수정·삭제·확정, AI 변환 결과 묶음, 후보 [🗑 삭제], 최종안 저장·마감, 비중으로 분량 맞추기 + '기록 제목을 넣어 시작', 세로 화면 배치, 맞춤법 검사 버튼)
   - 태그별 기록(필터, 필터된 기록 태그 바꾸기, 태그 AI 변환 ①시험 ②나머지 변환, 확정, 되돌리기)
   - 프롬프트 메뉴(목록·예시 탭, 예시 불러오기, 마법사 Chat/Form)
   - 내보내기(클립보드, xlsx, 세특 반별 시트 나누기, 1·2학기 합쳐 보기)
   - 설정(연결·모델, 역할·학년도, 분량·일정, 행특 사전, 세특 어휘, 기재 유의어, 글자 크기, 백업·자료, 🎁 설정 꾸러미 만들기·가져오기)
4. **최근 바뀐 곳은 더 자세히** (v0.31.2 ~ v0.33.0): 글자 크기(`--bs`), 제목 넣어 시작(`ai_extra_set`의 title_lead, `_fit`), 후보 삭제(`candDelBtn`), 맞춤법 검사(`open_speller`), 반별 시트(`export.write_xlsx` split), 설정 꾸러미(`app/share.py`, `share_*` API, 가져오기 겹침 처리·합치기·태그 프롬프트 넣기).
