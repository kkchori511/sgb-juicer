# Codex 재검토 반영 기록 (v0.9.0)

검토: docs/review/codex_recheck.md · 회귀 시험: tests/test_recheck_fixes.py(백엔드), Playwright 화면 시험(저장 순서·실패·버튼)

| 항목 | 반영 |
|---|---|
| N01 | 최종안 저장을 한 줄로 세워 차례대로 처리. 채택·마감은 같은 줄에서 앞선 저장이 끝난 뒤 실행하고, 성공하면 이전 초안은 더 저장하지 않음 |
| N02 | 학생·항목·학년도·화면 전환, 복원·학년도 삭제·업데이트 전에 남은 저장을 마치고, 실패하면 화면과 글을 그대로 둠. 최종안·성취기준 저장에 학년도를 붙여 서버가 지금 학년도와 다르면 거부. 창을 닫을 때도 남은 저장을 마친 뒤 닫음(실패 시 확인, 화면이 응답 없으면 다시 닫기로 바로 닫힘) |
| N03 | 성취기준·프롬프트 자동 저장을 대상별로 따로 미룸(다른 대상의 저장을 취소하지 않음). 성취기준 조회 응답에 요청 번호·과목·학년도 확인, 파일 가져오기도 연 시점의 과목·학년도로 저장 |
| N04 | 백업은 임시 폴더에 다 만든 뒤 게시(실패하면 목록에 없음). '완료' 표시 없는 백업(이전 형식·실패분)은 '이전 형식'으로 표시하고 복원해도 지금 스캔 원본은 그대로 둠 |
| N05 | 복원 교체 때 지금 파일을 옆(.복원이전)으로 옮겨 두고 바꾸며, 도중 실패하면 전부 되돌림. 복원 중 앱이 꺼지면 다음 실행 때 복원 전 상태로 되돌림 |
| N06 | 되돌리기 검사를 내용뿐 아니라 제목·날짜·비중·태그·후보(잠금 포함)까지, 검사와 되돌리기를 한 트랜잭션에서 |
| N07 | 관리 작업(복원·학년도 전환/생성/삭제·담당 삭제·업데이트)과 AI·OCR·일괄 작업을 한 잠금에서 서로 막음. 관리 작업 중 새 쓰기도 막음. AI 작업 표시는 결과 저장까지 유지 |
| N08 | 실행 잠금은 새 exe를 띄우기 바로 전에만 넘겨주고, 실패하면 되찾음. 되찾지 못하면 이 창의 쓰기를 막고 닫아 달라고 안내 |
| N09 | 직접 쓴 최종안이 저장되면 마감·다듬기 버튼과 학생 상태를 바로 맞춤 |

보류: M06(클립보드의 `=` 시작 글 — 실제 엑셀·NEIS에서 확인 후 결정), L02의 큰 파일 크기 제한(1.0 이후), L01·L03(1.0 직전).
