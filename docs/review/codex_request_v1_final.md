### 2. v0.35.0 → v0.35.3 바뀐 코드 점검(버그·회귀)
특히 아래를 읽어 주세요. 문제가 있으면 재현 조건과 심각도(높음/중간/낮음)를 적습니다.
- `app/scan.py` `extract_ids`: '이름:' 다음 줄 이름, 라벨 낱말 거르기(`RE_NOT_NAME`), 쌍점 필수 규칙. 진짜 이름을 놓치거나 본문 낱말을 이름으로 잡는 경우가 없는지, `strip_ids`/`strip_pages`가 이름 줄을 지우는지(AI로 학생 이름이 나가지 않는지).
- `app/web/app.js`:
  - `stepsHtml`과 그것을 쓰는 안내 창 10곳, `typedConfirm({ html })`: 바깥 값(백업 이름, 학번·이름 목록, 모델 이름, 키 이름)이 `escHtml`로 감싸져 HTML 주입이 없는지.
  - `tvSyncOrig`(태그별 기록 저장·되돌리기·다시 불러오기 뒤 원문 값), 결과 묶음 요약 '최신'(원문 제외), `eulReul`.
  - `chev()`·`watchTriangles`(MutationObserver로 ▲▼◀▶▾를 `.tri`로 감쌈): 무한 반복, 입력 중 글자(편집 칸)·사용자 글 훼손, 성능 문제가 없는지. `characterData` 감시가 타이핑 중인 칸에 끼어들지 않는지.
  - DOM `append`에 null이 들어갈 수 있는 남은 곳(W10과 같은 'null' 글자).
  - OCR 읽는 방식 화면(`renderScanStart`): 기본값 CLOVA만, 키가 없을 때 고를 수 있는 방식, 가림 미리보기·동의 흐름.
- `app/web/style.css` 끝의 덮어쓰기 블록('모양 일관성', '읽는 방식', 꺾쇠·세모, OCR 화면): 다른 화면을 깨뜨릴 만큼 넓은 선택자가 없는지(예: `span.tag`, `button.link`, `details:not(...) > summary::before`, `.steps-bar > span !important`).
- `requirements.txt` pypdfium2 5.15.2.
