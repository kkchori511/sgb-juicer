  2. Credits 메뉴에서 크레딧을 충전합니다. (1크레딧 = 1달러) 무료 모델만 쓸 때는 충전하지 않아도 됩니다.

  4. 키는 만들 때 한 번만 보이니 안전한 곳에 따로 보관하세요.

AI 모델 (4칸)

작업할 때 4개 중 하나를 고릅니다. [모델 페이지]에서 모델 ID(예: google/gemini-2.5-flash)를 복사해 [붙여넣기]를 누르세요. 1번 칸에는 무료 모델이 들어 있습니다.

켜면 데이터를 수집·보관하지 않는 제공자에게만 보냅니다(data_collection: deny, zdr: true). 쓸 수 있는 모델이 줄어들고, 무료 모델과 대부분의 Google 모델은 실패할 수 있습니다. 계정 전체에 적용하려면 OpenRouter 개인정보 설정을 이용하세요.

CLOVA OCR (스캔 PDF를 쓸 때만)

종이 학습지를 스캔한 PDF를 글자로 읽을 때만 필요합니다. 네이버 클라우드 플랫폼에 가입하고 CLOVA OCR API를 설정해야 합니다.

CLOVA OCR 가입 - 키 발급 안내 펼치기
키는 이 프로그램 폴더의 설정 파일()에 평문으로 저장됩니다. 공용 PC에서는 사용 후 반드시 [키 초기화]를 눌러 주세요. [키 초기화]는 키만 지우며 학생 자료는 지우지 않습니다.
API 키는 본인이 발급받은 키만 사용해야 하며, 타인의 키를 무단으로 사용하는 것은 금지됩니다.

유의 사항 및 안내

스캔 PDF(CLOVA OCR)

  • 스캔 PDF를 글자로 읽을 때 스캔 이미지가 그대로 네이버 CLOVA OCR로 전송됩니다. 손으로 쓴 이름·학번도 함께 전송됩니다.
  • 이 점이 걱정된다면 스캔하기 전에 인적사항을 직접 가려(마스킹) 주세요. 앱이 이미지 속 인적사항을 가려 주지는 않습니다.
  • 가져온 스캔 PDF의 사본과 인식한 글자는 원본 보기를 위해 자료 폴더의 스캔에 보관됩니다. 인박스에서 그 묶음을 지우면 함께 지워집니다.
  • 학번·이름은 앱이 규칙으로 읽고(AI 미사용), AI에는 학번·이름 줄을 뺀 내용만 보냅니다.

AI(OpenRouter)

  • AI에는 학번·이름을 빼고 내용만 보냅니다. 학생과 기록의 연결은 이 PC 안에서만 관리합니다.
  • 설정에서 OpenRouter 학습 차단을 켜면 데이터를 수집·보관하지 않는 제공자에게만 보냅니다. 켜면 쓸 수 있는 모델이 줄어듭니다(무료 모델, 대부분의 Google 모델 등).
  • 계정 전체에 적용하려면 OpenRouter 개인정보 설정에서 같은 제한을 켜 두는 것을 권합니다.
  • 무료 모델은 제공자가 데이터를 수집할 수 있고, 분당 호출 수 제한이 있어 많은 학생을 한 번에 처리하면 느리거나 실패할 수 있습니다.

키와 자료 보관

  • API 키와 학생 자료는 프로그램 옆 생기부착즙기_데이터 폴더에 평문으로 저장됩니다.
  • 공용 PC에서는 사용 후 설정 > 키 초기화를 눌러 주세요. 학생 자료는 지워지지 않으니 필요하면 자료 폴더도 정리해 주세요.
  • 프로그램을 다른 사람에게 줄 때는 exe 파일만 전달하세요. 자료 폴더에는 학생 자료가 들어 있습니다.
  • API 키는 본인이 발급받은 키만 사용해야 하며, 타인의 키를 무단으로 사용하는 것은 금지됩니다.
