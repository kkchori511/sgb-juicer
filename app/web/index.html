처음 사용하시나요? OpenRouter 가입 - 키 발급 안내 펼치기
  1. openrouter.ai에 가입하고 로그인합니다.
  2. Credits 메뉴에서 크레딧을 충전합니다. (1크레딧 = 1달러) 무료 모델만 쓸 때는 충전하지 않아도 됩니다.
  3. Keys 메뉴에서 Create Key를 눌러 키를 만들고, 아래 칸에 붙여넣습니다.
  4. 키는 만들 때 한 번만 보이니 안전한 곳에 따로 보관하세요.

AI 모델 (4칸)

작업할 때 4개 중 하나를 고릅니다. [모델 페이지]에서 모델 ID(예: google/gemini-2.5-flash)를 복사해 [붙여넣기]를 누르세요. 1번 칸에는 무료 모델이 들어 있습니다.

켜면 데이터를 수집·보관하지 않는 제공자에게만 보냅니다(data_collection: deny, zdr: true). 쓸 수 있는 모델이 줄어들고, 무료 모델과 대부분의 Google 모델은 실패할 수 있습니다. 계정 전체에 적용하려면 OpenRouter 개인정보 설정을 이용하세요.

CLOVA OCR (스캔 PDF를 쓸 때만)

종이 학습지를 스캔한 PDF를 글자로 읽을 때만 필요합니다. 네이버 클라우드 플랫폼에 가입하고 CLOVA OCR API를 설정해야 합니다.

CLOVA OCR 가입 - 키 발급 안내 펼치기
키는 이 프로그램 폴더의 설정 파일()에 평문으로 저장됩니다. 공용 PC에서는 사용 후 반드시 [키 초기화]를 눌러 주세요. [키 초기화]는 키만 지우며 학생 자료는 지우지 않습니다.
API 키는 본인이 발급받은 키만 사용해야 하며, 타인의 키를 무단으로 사용하는 것은 금지됩니다.

1. 처음 설정

  1. 연결: OpenRouter API 키를 붙여넣고 [연결 확인]을 누릅니다. 키 발급은 안내를 펼쳐 차례대로 따라 하세요. 1번 모델 칸에는 무료 모델이 들어 있습니다.
  2. 담당: 학년도와 담임/비담임을 고르고, 담임이면 학년·반을 넣습니다. 맡은 과목(학기 지정)과 동아리를 추가합니다. 과목은 학기마다 따로 등록합니다(예: 공통수학1은 1학기, 공통수학2는 2학기).
  3. 명렬: 담당마다 엑셀에서 학번·이름 칸을 복사해 [클립보드에서 추가] 하거나 파일(여러 개 가능)을 추가합니다. 붙여넣기와 파일을 섞어 계속 이어서 넣을 수 있습니다. 나중에 해도 됩니다.
  4. 일정: 학교 생기부 마감 일정을 넣으면 현황판 맨 위에 D-day로 보입니다.

스캔 PDF를 쓰려면 CLOVA OCR 키도 필요합니다(설정 > 연결·모델, 네이버 클라우드 플랫폼 가입).

2. 명렬·담당 관리

  • 붙여넣으면 학번·이름·학년·반·번호·성취수준 열을 자동으로 찾습니다. 틀리면 위쪽 열 연결을 바꾸세요. 학번이 없으면 학년·반·번호로 5자리 학번을 만듭니다.
  • 노란 행(학번 중복, 다른 반 등)을 고쳐야 [명렬 반영]이 눌립니다. 칸을 눌러 바로 고칠 수 있습니다.
  • 명렬을 다시 넣으면 그 담당의 명렬이 바뀝니다. 새 명렬에 없는 학생은 기록이 있으면 비활성, 없으면 빠집니다.
  • 비활성화(전출 등): 학생을 체크하고 [선택 학생 비활성화]. 이 담당에서만 빼거나, [모든 소속에서(전출)]로 한 번에 뺄 수 있습니다. 기록은 지우지 않으며 매칭 후보·일괄 처리·내보내기에서 빠집니다.
  • 과목은 성취수준 3단계/5단계와 학생별 성취수준을 넣을 수 있고, 과목·동아리마다 목표 분량을 바꿀 수 있습니다.

3. 자료 인박스

여러 학생의 자료(학습지, 엑셀 기록)를 한 번에 학생별로 나눠 항목에 보내는 곳입니다.

  1. 새 자료 묶음: 이름과 대상 명렬·보낼 항목을 정합니다.
  2. ① 가져오기: 엑셀 칸을 드래그해 복사한 뒤 [엑셀 붙여넣기], 또는 xlsx·스캔 PDF.
    • 여러 학생에게: 학생이 행인지 열인지, 학번·이름 줄, 첫 줄이 날짜·회차 제목인지 고릅니다(대부분 자동). 셀 하나가 기록 한 건이 됩니다.
    • 한 학생에게 여러 건: 학생을 고르고 읽는 순서(행 우선/열 우선)를 정합니다.
    • 왼쪽 원본 미리보기의 색과 오른쪽 '만들어질 기록'을 확인하고 [확정하고 매칭으로].
  3. ② 학생 매칭: 학번·이름이 모두 맞으면 자동 확정, 이름만 맞거나 비슷하면 추천입니다. 추천은 원본과 대조한 뒤 확정하세요. 백지·다른 반 자료는 [제외]. 확인 필요가 0이어야 다음으로 갑니다. 명렬이 없으면 [명렬 등록하러 가기] 후 [매칭으로 돌아가기].
  4. ③ AI 정제(선택): 맞춤법·문장을 다듬고 싶을 때만. 원문과 정제 후보 중 보낼 내용을 고릅니다.
  5. ④ 보내기 검토: 보낼 항목·날짜·태그를 정하고 'N명에게 M건'을 확인한 뒤 보냅니다. 마감된 학생이 있으면 [마감 해제하고 보내기] 또는 [제외하고 보내기]. 보낸 묶음은 다시 보낼 수 없습니다(중복 방지).

3-1. 스캔 PDF

  1. [🖨 스캔 PDF]로 파일을 고르고 학생 1명당 페이지 수(단면 1, 양면 2)를 넣은 뒤 [OCR 시작]. 스캔 이미지는 CLOVA OCR로 그대로 전송됩니다. 걱정되면 스캔 전에 인적사항을 가리세요.
  2. 페이지 묶기: 학생 경계가 밀렸으면 페이지의 [여기서 새 학생]을 켜고 끄고, 백지·표지는 [빼기]. OCR은 다시 하지 않습니다.
  3. 학번·이름은 각 학생 첫 페이지 머리글에서 규칙으로 읽고(AI 미사용), 그 줄은 내용에서 지웁니다.
  4. 매칭에서 [원본 보기]로 스캔 그림과 인식 글자를 나란히 볼 수 있습니다.

4. 항목별 기록 (학생 편집)

  • 왼쪽 학생 목록 → 가운데 누가기록 → 오른쪽 최종안·후보. [이전/다음 학생](Alt+↑/↓)으로 넘깁니다. 상태 필터로 '입력 중만' 같이 볼 수 있습니다.
  • + 누가기록: 날짜·활동명·태그·내용. 회차는 자동으로 붙습니다.
  • 이미 쓴 생기부 넣기: 작성해 둔 문장을 '기존 완성문'으로 넣어 [다듬기(AI)] 하거나 [그대로 최종안으로]. 여러 학생은 위 줄의 [📥 이미 쓴 생기부 일괄 입력](이름·내용 열 복사), 누가기록은 [📥 누가기록 일괄 입력], 기존 완성문을 한꺼번에 최종안으로 보내려면 [✔ 기존 완성문 → 최종안 일괄]. 누가기록 날짜는 [날짜 넣기]를 켤 때만 들어갑니다. ▾를 누르면 칸을 접습니다.
  • 정제(AI): 기록 한 건을 다듬은 후보를 만듭니다. [이 내용으로 기록 바꾸기]를 눌러야 기록이 바뀌고, 원문은 남습니다.
  • 이동: 기록이나 문단을 그 학생이 속한 다른 항목(자율↔진로↔행특, 과목·동아리)으로 옮깁니다. 직후 [되돌리기] 가능.

5. 종합 · 최종안 · 마감

  1. 기록을 체크하고 [선택 기록 종합하기]. 비중(%)은 결과 문장에서 차지할 분량 비율입니다. 비우면 기록 길이에 비례해 나눕니다. [비중 합계 100% 검사]를 켜면 합이 100%여야 실행됩니다.
  2. 지침·예시를 그 자리에서 고칠 수 있습니다. 예시를 넣으면 AI가 문체·형식을 반드시 따릅니다.
  3. 결과는 오른쪽 후보에 쌓입니다. 후보는 최근 3개까지(잠금 포함) 보관되고, 4번째부터 잠기지 않은 가장 오래된 것이 지워집니다. 남기고 싶은 후보는 [🔓 보관 잠금].
  4. [✔ 최종안으로 채택] 또는 최종안 칸에 직접 써서 [직접 고친 내용 저장]. [다듬기(AI)]로 최종안을 다시 다듬을 수 있습니다.
  5. 검토가 끝나면 [● 마감]. 마감하면 기록·AI·최종안 편집이 잠깁니다(조회·복사·내보내기는 됨). 고치려면 [마감 해제]. 분량을 넘으면 빨갛게 표시하지만 마감은 됩니다.
  6. 채택한 뒤 기록이 바뀌면 "채택 후 기록이 바뀌었습니다" 경고가 뜹니다.

6. 일괄 종합

항목을 고르면 학생마다 처리 가능 여부가 미리 나옵니다(마감·후보 3개 잠김·기록 없음·비활성은 제외). [종합 실행]을 누르면 학생마다 모든 기록을 저장된 비중(없으면 길이 비례)으로 종합합니다. 진행 중 [중지]할 수 있고, 끝나면 [실패한 학생만 다시 실행]. 결과는 각 학생의 후보에 들어가니 학생 화면에서 확인·채택하세요.

7. 성취기준 (과목 세특)

  • 메뉴 [성취기준]에서 과목마다 붙여넣기·PDF(글자 있는 문서)·한글(hwpx)로 넣고 필요한 부분만 남깁니다. 학년도마다 따로 저장됩니다.
  • 세특 종합 창에서 [성취기준 사용]을 켜면 기록을 성취기준 관점에서 해석하고, 학생의 성취수준에 맞는 표현 수위로 씁니다.
  • 기록이 없는 학생은 [성취기준만으로 생성](성취수준 필수). 결과에는 "기록 없음, 성취기준으로 생성" 표시가 남으니 실제 수업 모습과 맞는지 꼭 확인하세요.

8. 검토 · 내보내기

  • 항목을 고르면 학생별 최종안이 표로 나옵니다. 기본은 모두, 옵션으로 마감만.
  • 미마감 학생은 노란색으로 표시하고 xlsx·복사에 '상태' 열로 알립니다. 최종안 문장에는 표시를 넣지 않습니다. 최종안이 없는 학생은 빈칸으로 남겨 줄이 맞습니다.
  • [클립보드 복사] 후 엑셀이나 NEIS에 붙여넣거나, [xlsx 저장]. 셀 병합은 없고 한 행에 학생 한 명입니다. 복사 범위를 '최종안만'으로 바꿀 수 있습니다.

9. 현황판

  • 맨 위: 다가오는 일정과 D-day(7일 이내 주황, 당일 빨강).
  • 카드: 담임반·과목(선택한 학기)·동아리. 카드를 누르면 아래 표가 바뀝니다. 담임 표는 학생×항목 상태, 과목·동아리 표는 반·상태 필터가 있습니다.
  • 상태: ○ 기록 없음 · ◐ 입력 중 · ◑ 최종안 있음 · ● 마감. 행이나 칸을 누르면 그 학생의 기록으로 갑니다.
  • 다음 할 일: 명렬 등록, 인박스 확인, 최종안 만들기, 마감 검토, 채택 후 변경을 순서대로 알려 줍니다.

10. 설정 · 프롬프트 · 태그

  • 모델 4칸: 모델 ID를 넣으면 단가가 보입니다. 작업 화면 오른쪽 위에서 고릅니다.
  • OpenRouter 학습 차단(기본 꺼짐): 켜면 데이터를 수집·보관하지 않는 제공자에게만 보냅니다. 무료 모델 등은 쓸 수 없게 될 수 있습니다.
  • 프롬프트: 항목(자율·진로·행특·세특·동아리) × 작업(기록 정제·다듬기·종합)마다 지침과 예시를 고칩니다. [기본값으로 되돌리기] 가능.
  • 분량: 행동특성 및 종합의견 900바이트, 나머지 1500바이트가 기본입니다(한글 1자 = 3바이트).
  • 태그: 메뉴 [태그]에서 만들고, 기록에는 목록에서 골라 붙입니다(표현 통일).

11. 백업 · 업데이트 · 학년도

  • 모든 자료는 프로그램 옆 생기부착즙기_데이터 폴더에 저장되고, 바꿀 때마다 자동 저장됩니다(상단 '저장됨').
  • 앱을 켤 때 하루 한 번 자동 백업(최근 7개). 설정 > 백업·자료에서 [지금 백업]·[이 백업으로 복원].
  • 새 버전이 나오면 상단에 알림이 뜹니다. [지금 업데이트]를 누르면 백업 후 새 버전으로 바뀌어 다시 켜집니다.
  • 새 학년도는 설정 > 역할·학년도에서 시작합니다. 이전 학년도는 상단에서 골라 조회만 할 수 있습니다.
  • 다른 PC로 옮길 때는 exe와 자료 폴더를 함께 복사하세요. 다른 사람에게 줄 때는 exe만 주세요.

자주 묻는 질문

AI가 "제공자 없음"이라며 실패해요.
학습 차단을 켜 두었거나 그 모델을 처리할 제공자가 없는 경우입니다. 다른 모델을 고르거나 설정에서 학습 차단을 확인하세요.
"속도 제한"이 떠요.
무료 모델은 분당 호출 수 제한이 있습니다. 잠시 뒤 다시 하거나 유료 모델(2~4번 칸)을 쓰세요.
후보를 만들 수 없다고 해요.
후보 3개가 모두 잠겨 있으면 새로 만들 수 없습니다. 하나의 잠금을 푸세요.
기록이 고쳐지지 않아요.
마감된 항목입니다. 오른쪽 [마감 해제] 후 고치세요. 이전 학년도는 조회만 됩니다.
매칭에서 학생이 안 나와요.
대상 명렬에 없거나 비활성 학생입니다. [명렬 등록·수정]에서 확인하세요.
업데이트가 실패했어요.
화면의 문구와 자료 폴더의 업데이트_기록.txt를 확인하세요. 릴리스 페이지에서 exe를 내려받아 덮어써도 됩니다(자료는 그대로).

유의 사항 및 안내

스캔 PDF(CLOVA OCR)

  • 스캔 PDF를 글자로 읽을 때 스캔 이미지가 그대로 네이버 CLOVA OCR로 전송됩니다. 손으로 쓴 이름·학번도 함께 전송됩니다.
  • 이 점이 걱정된다면 스캔하기 전에 인적사항을 직접 가려(마스킹) 주세요. 앱이 이미지 속 인적사항을 가려 주지는 않습니다.
  • 가져온 스캔 PDF의 사본과 인식한 글자는 원본 보기를 위해 자료 폴더의 스캔에 보관됩니다. 인박스에서 그 묶음을 지우면 함께 지워집니다.
  • 학번·이름은 앱이 규칙으로 읽고(AI 미사용), AI에는 학번·이름 줄을 뺀 내용만 보냅니다.

AI(OpenRouter)

  • AI에는 명렬의 학번·이름을 빼고 내용만 보냅니다. 다만 기록 본문에 직접 적은 이름·학번은 앱이 지우지 않으니, 보내기 전에 본문을 확인하세요. 학생과 기록의 연결은 이 PC 안에서만 관리합니다.
  • 설정에서 OpenRouter 학습 차단을 켜면 데이터를 수집·보관하지 않는 제공자에게만 보냅니다. 켜면 쓸 수 있는 모델이 줄어듭니다(무료 모델, 대부분의 Google 모델 등).
  • 계정 전체에 적용하려면 OpenRouter 개인정보 설정에서 같은 제한을 켜 두는 것을 권합니다.
  • 무료 모델은 제공자가 데이터를 수집할 수 있고, 분당 호출 수 제한이 있어 많은 학생을 한 번에 처리하면 느리거나 실패할 수 있습니다.

키와 자료 보관

  • API 키와 학생 자료는 프로그램 옆 생기부착즙기_데이터 폴더에 평문으로 저장됩니다.
  • 공용 PC에서는 사용 후 설정 > 키 초기화를 눌러 주세요. 학생 자료는 지워지지 않으니 필요하면 자료 폴더도 정리해 주세요.
  • 프로그램을 다른 사람에게 줄 때는 exe 파일만 전달하세요. 자료 폴더에는 학생 자료가 들어 있습니다.
  • API 키는 본인이 발급받은 키만 사용해야 하며, 타인의 키를 무단으로 사용하는 것은 금지됩니다.

AI 결과

  • AI가 만든 문장은 초안입니다. 학생의 실제 활동과 맞는지 선생님이 반드시 확인한 뒤 마감해 주세요.
