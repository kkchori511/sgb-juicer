1. console.ncloud.com에서 네이버 클라우드 플랫폼(NCP) 계정을 만들고 로그인합니다. (결제수단 등록이 필요할 수 있습니다.)
  2. 콘솔 상단 전체 서비스 → AI·Application Service → AI Services → CLOVA OCR 메뉴로 들어갑니다.
  3. 처음이라면 이용 신청/약관 동의 화면이 한 번 나올 수 있습니다. 동의 후 진행하세요.
  4. Domain 생성 버튼을 눌러 새 도메인을 만듭니다. PDF/이미지 일반 텍스트 추출이 목적이면 General(일반) 템플릿을 선택하면 됩니다.
  5. 도메인 이름을 입력하고 생성하면, 해당 도메인 상세 페이지로 이동합니다.
  1. 방금 만든 도메인 상세 페이지에서 API Gateway 연동 항목을 찾아 활성화로 켭니다. (꺼져 있으면 Invoke URL이 생성되지 않습니다.)
  2. 활성화하면 자동으로 API Gateway 제품이 함께 생성되고, 같은 화면에 다음 두 값이 표시됩니다.
    • Secret Key — X-OCR-SECRET 헤더에 넣는 값
    • API Gateway Invoke URL — General OCR 엔드포인트, 보통 .../general로 끝남
  3. 이 두 값을 그대로 복사해서 아래 CLOVA Secret Key / CLOVA Invoke URL 칸에 붙여넣으면 됩니다.
  4. Secret Key가 유출됐거나 바꾸고 싶다면 같은 도메인 화면에서 재발급할 수 있습니다. 재발급하면 이 프로그램에도 새 값을 다시 입력해야 합니다.
